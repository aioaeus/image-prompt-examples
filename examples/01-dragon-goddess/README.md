- Change the character: edit hair, hairpins, makeup and expression in paragraph 1; adjust the dragon's scale colours in paragraph 2 — the composition stays intact.
- Change the palette: replace `crimson red, antique gold, ivory and black` as a set (e.g. blue-and-white porcelain tones) and the whole image follows.
- No dragon: swap the dragon paragraphs for a phoenix or giant serpent, and update `deformed dragon` in the negative prompt to match.
