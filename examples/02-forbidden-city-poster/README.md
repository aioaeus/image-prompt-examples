# 案例 02：故宮建築極簡海報 | Case 02: Forbidden City Minimalist Poster

![效果圖 / Result](image.png)

極簡高端藝術海報：建築插畫居中，超大英文字體與建築輪廓呼應，小字註解點綴。

A minimalist premium art poster: a central architectural illustration, oversized English typography echoing the building's silhouette, with small annotation text around it.

## 完整提示詞 / Full Prompt

```
以作为核心视觉元素，创作一张极致简约的高端艺术海报。画面中央放置建筑的插画图形，背景以超大加粗的英文字体呈现，字体造型与建筑轮廓形成呼应，突出主建筑，字体淡化处理。环绕主体布置小号文字，阐释它的设计理念与哲思，并配以中文注解。整体调性典雅克制，色彩选择与建筑气质相契合一一部分文字或图形可巧妙延展为建筑的构件或外轮廓的延伸，营造浑然一体的构图。最终呈现一张高级感十足、极简且富有张力的艺术海报。
```

## 適用模型 / Recommended Models

適用於理解中文長指令與版式設計的模型：GPT Image（Image2）、即夢、Flux。海報類提示詞優先選能處理文字排版的模型。

Best on models that follow long Chinese instructions and layout design: GPT Image (Image2), Jimeng, Flux. For poster work, prefer models with strong text/layout handling.

## 修改說明 / How to Adapt

- 提示詞開頭「以……作為核心視覺元素」的空位要填主體建築名，例如「以故宮太和殿作為核心視覺元素」。
- 換城市／建築：只換建築名與對應配色（如改成水墨黑白），版式描述保持原樣就能批量出系列海報。
- 想要留白更多：加一句「減少周圍小字數量，保留大面積留白」。

- Fill in the opening blank with your subject building, e.g. 「以故宮太和殿作為核心視覺元素」("with the Hall of Supreme Harmony as the core visual element").
- Change city/building: swap only the building name and its palette (e.g. ink black-and-white) and keep the layout wording — you can produce a whole poster series this way.
- For more negative space: add 「減少周圍小字數量，保留大面積留白」("fewer annotation texts, keep generous white space").
